# 新手图文指南

先用示例成功生成一份 PDF，再开始写自己的论文。第一次不用理解所有按钮，也不用先学会 LaTeX。

如果想边看边练，请打开 [AI 示例图文实操](AI_WALKTHROUGH.md)，从改姓名和一段文字开始。本页可作为日常使用时的操作参考。

## 1. 下载正确的文件

打开 [Releases](https://github.com/Kayvion-Hong/xit-markdown-thesis-assistant/releases)，找到版本下的 **Assets**，下载 `xit-v0.6.0-beginner-windows.zip`。

注意区分：

| 下载项 | 用途 |
| --- | --- |
| `xit-v0.6.0-beginner-windows.zip` | 完整运行包，包含 Python、Pandoc 和 TeX 环境 |
| `Source code (zip)` / `Source code (tar.gz)` | 开发用源码，需要自己配置环境 |

下载后右键解压，选择较短的路径，例如 `D:\XIT`。进入解压后的文件夹，确认 `启动论文助手.bat`、`markdown` 和 `runtime` 在同一级。不要只拖出一个 BAT，也不要在压缩软件里直接双击运行。

## 2. 第一次启动，先练习

双击 `启动AI示例教学.bat`。启动窗口会显示本机网页地址，并尝试打开浏览器。使用期间保留启动窗口；浏览器没有自动打开时，将窗口里的完整地址复制到浏览器地址栏。

![开始页和运行环境检查](images/01-home.png)

检查 Python、Pandoc、XeLaTeX 和 Biber 是否就绪。它们分别负责运行助手、转换 Markdown、排版及处理参考文献。完整包通常不需要手动配置这些程序；缺少程序时先确认下载的是完整包且已全部解压。

本页截图来自 AI 教学模式。正常启动自己的论文时，页面标题和内容会不同。AI 模式与普通模式的文稿分开保存。

第一次点击“4 检查与导出”，然后点击“生成 PDF”。等待成功提示，再打开生成结果。先确认原示例能够编译，有助于区分环境问题和后续写作错误。

## 3. 填写封面资料

点击“2 填写资料”，依次填写中文题目、英文题目、姓名、学号、专业、年级、指导教师、日期及关键词。

![基本资料表单](images/02-metadata.png)

练习时只把示例姓名改为“练习学生”，点击“保存基本资料”，重新生成 PDF，检查封面是否更新。熟悉后再填写自己的真实信息。关键词按输入框提示用逗号分隔。

题目过长可能触发封面宽度检查。此时按照提示调整题目，并与指导教师确认；程序不会为了塞进封面而自动缩小模板字号。

## 4. 写一段正文，看右侧变化

点击“3 写论文”，在“当前内容”中选择章节。左侧是可编辑的 Markdown，右侧是最近一次成功编译的 PDF。

![Markdown 与 PDF 左右对照](images/03-live-preview.png)

先在绪论正文后空一行，输入：

```markdown
这是一段用于学习排版的练习文字。

其中的 **关键术语** 可以加粗。
```

停止输入，等待“内容已同步”。勾选“停止输入 3 秒后自动编译”时，助手会发起编译；也可以点击“立即编译”。编译需要时间，右侧不会每输入一个字就立刻变化。出错时可能继续显示旧 PDF，请先看状态和日志。

常用写法如下：

```markdown
# 绪论

## 研究背景

这是正文。两个段落之间留一个空行。

### 研究对象

**需要加粗的文字**
```

每章保留一个 `#` 章标题，`##` 表示节，`###` 表示小节。`#` 后留一个空格。不要手写“第 1 章”或“1.1”，编号由模板生成。摘要只写正文，不要添加章标题。Markdown 编辑区的字号不决定最终 PDF 字号。

### 如何看完整 PDF

把鼠标放在右侧 PDF 上滚动，就能连续阅读整篇论文。也可在“页”输入框输入 PDF 页序号后按回车；它与正文页脚印刷的页码不一定相同。

缩放可选“适合宽度”“适合整页”，或 25% 至 300%。需要更细的大小时，填写右侧百分比。缩放只影响屏幕显示，不改变导出的论文格式。

### 如何从文字找到排版位置

先成功编译一次，再双击左侧某段正文，或将光标放入正文后点“定位到 PDF”。反过来，双击 PDF 正文可跳到对应源内容。定位按段落或内容块进行，并非逐字精确；封面、自动生成的目录和参考文献等位置不一定支持对应定位。修改后先重新编译，以免新旧内容不匹配。

## 5. 章节不必固定为五章

点击“管理章节（增减 / 排序）”。

![章节新增、排序和移出操作](images/04-chapters.png)

要增加章节，点“＋ 新增一章”，填写“拓展实验”等标题，不用输入章号。通过“上移”“下移”调整顺序。“移出正文（保留文件）”会停止编译该章，文件仍保留，可恢复到正文末尾。至少保留一章。

完成后重新编译，检查目录和编号。正文里“全文共分为五章”这样的叙述、对已移出图表的引用，需要自己修改。总结、谢辞与附录不属于这个正文章节列表。

## 6. 插入图片、表格和公式

先把光标放在完整段落后的空行，再点工具栏按钮，避免把内容插进已有表格或公式内部。

**图片：** 点击“插入图片”并选择文件，按提示填写图题。助手会保存图片并插入引用所需的标记。修改图题时只改方括号里的文字，先保留路径和标签。新插入的图片不会自动替换旧图。

**三线表：** 在 Excel 中选中一个完整矩形区域并复制，点击“三线表”，填写标题，再粘贴数据。第一行用作表头。不要把列之间的制表符换成空格。生成 PDF 后检查列宽、换行及表题；内容过宽时需要减少文字或调整表格结构。

**编号公式：** 点击“编号公式”，先尝试 `y = ax + b`，不要在输入框另加 `$$`。插入后保留生成的标签和引用，编译后检查编号是否正常。复杂公式需要学习相应数学语法。

## 7. 引用文献

将光标放在需要引用的句子末尾，点击“文献引用”。

![选择已有文献或导入 BibTeX](images/05-references.png)

可以选择已有条目，也可以选择“＋ 填写新文献”或“＋ 导入 BibTeX 文件”。导入后再选择具体条目引用。正文中的 `[@文献代号]` 会在编译后显示为引用编号。

“当前内容”中的“参考文献库”用于查看原始 BibTeX。新手优先通过文献按钮操作，避免误删括号、逗号或代号。更改文献代号后，正文引用必须同步更改。

AI 示例含演示占位文献。编译通过只能说明格式可处理，不能证明文献真实、信息准确或支持正文结论。正式论文请核对原始来源、作者、年份、题名及 DOI。

## 8. 保存、撤销与恢复

| 遇到的情况 | 建议操作 |
| --- | --- |
| 刚打错一句话 | `Ctrl+Z` 或“撤销” |
| 撤销过头 | `Ctrl+Y` / `Ctrl+Shift+Z` 或“重做” |
| 想立即保存 | `Ctrl+S` 或“保存当前内容” |
| 想找回较早的某个文件 | “历史版本 / 恢复”，核对文件和时间 |
| 准备大幅改动整篇论文 | 先点“整篇备份 / 回退”保存一个备份 |
| 意外关闭后出现草稿提示 | 先查看草稿，再确认是否恢复 |

![整篇备份与回退窗口](images/06-backup.png)

正文停止输入约 1.2 秒后保存，资料约 1.6 秒后保存。离开前确认“内容已同步”。撤销用于当前编辑过程，文件历史用于较早的保存版本，整篇备份还包含资料、章节顺序、图片和文献。

浏览器本地草稿是额外保护，不等于云端备份。请使用原浏览器和原项目位置重新打开；不要在恢复前清理浏览器数据、切换无痕模式或移动项目。重要修改后，把整篇备份或关闭后的整个项目文件夹复制到其他磁盘。

## 9. 检查和导出

在写作页点“返回功能菜单”，进入“4 检查与导出”。

![检查、生成 PDF 和定稿检查](images/08-export.png)

1. 点击“开始检查”，处理缺失图片、重复标签或文献引用错误。
2. 点击“生成 PDF”，等待完成后点击“打开生成的 PDF”。
3. 定稿前点击“开始定稿检查”，补齐姓名、学号等占位信息。
4. 人工逐页查看封面、目录、图表、公式、参考文献和附录，按学校当年要求核对。

若缺少原模板字体，可以先“用随包字体生成预览 PDF”。替代字体可能影响字形、行宽和分页，不能将此预览直接等同于原字体定稿。

导出的 PDF 由本机生成。浏览器下载或另存时，请选择自己容易找到的位置。预览页正在显示的旧结果不能代替本次成功导出。

## 10. 从练习转到自己的论文

![九项 AI 教学练习](images/07-ai-tutorial.png)

建议依次完成：生成原示例、改姓名、改正文、改图题并插表、插公式、核对模拟数据、引用文献、增减章节、查看代码附录。每次只改一项，再编译比较。

完成练习后回首页，在“新建 / 打开论文”中新建普通论文。v0.6 将论文保存在用户文档目录的独立文件夹，首页显示实际路径。教学内容不会自动成为正式论文。新版入口、插入预览与迁移步骤见 [v0.6 图文指南](UPGRADE_0_6.md)。

下一次继续写作时，再双击相同文件夹中的启动文件即可。已有环境齐全时，日常编辑和编译不需要联网。
