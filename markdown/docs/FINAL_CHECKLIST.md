# 毕业论文定稿检查清单

自动检查只能发现结构问题，不能代替最终人工审阅。

## 先运行自动检查

```bash
python xit.py final-check
python xit.py pdf
```

确认 `build/build-report.txt` 没有需要处理的警告。

## 封面

- [ ] 中文题目正确且没有占位文字
- [ ] 英文题目正确
- [ ] 姓名、学号、专业、年级、指导教师、日期正确
- [ ] 学校标识正常
- [ ] 长题目没有明显溢出或异常换行

## 摘要

- [ ] 中文摘要内容完整
- [ ] 中文关键词正确
- [ ] 英文摘要与中文摘要对应
- [ ] 英文关键词正确
- [ ] 没有手工重复写“摘要”“Abstract”“关键词”标题

## 目录与正文

- [ ] 目录章、节、小节与正文一致
- [ ] 章节编号由系统生成，没有手工重复编号
- [ ] 页码正确
- [ ] 没有 `??`
- [ ] 没有明显空白页或异常分页

## 图片、表格、公式、代码

- [ ] 所有图片清晰
- [ ] 图题与正文引用一致
- [ ] 表格没有越过页边
- [ ] 三线表格式正常
- [ ] 公式编号与引用正确
- [ ] 代码没有越过页边
- [ ] 图、表、公式编号没有手工写死

## 参考文献

- [ ] 每一条正文引用都有对应 BibTeX 条目
- [ ] 文献作者、题目、期刊/出版社、年份等信息经过人工核验
- [ ] 没有把示范论文的占位文献当作真实参考文献
- [ ] 文献列表没有 `??` 或空编号

## 末尾部分

- [ ] 总结标题正确
- [ ] 谢辞标题正确
- [ ] 附录编号和标题正确
- [ ] 无附录时没有空附录页

## 最终人工检查

- [ ] 使用学校/学院当年最新要求逐项核对
- [ ] 在最终提交环境重新构建一次
- [ ] 打开最终 PDF 从第一页看到最后一页
- [ ] 保留 `thesis/` 源文件和 Git 历史备份
