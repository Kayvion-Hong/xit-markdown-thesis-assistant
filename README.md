# XIT Markdown 毕业论文助手

在左侧用 Markdown 写论文，在右侧查看 LaTeX 编译后的 PDF。这个本地写作工具基于厦门工学院毕业论文模板，提供资料填写、章节管理、图表和文献插入、自动保存及备份恢复，适合希望少接触 LaTeX 源码的同学。

本项目由学生根据厦门工学院本科毕业论文（设计）的 Word 格式要求独立实现。正式提交前，请以学校、学院和指导教师当年发布的要求为准。

![第二章的 Markdown 与 PDF 左右对照](docs/images/03-live-preview.png)

左侧输入文字，右侧查看编译后的论文。日常写作可以在本机浏览器中完成，不需要注册在线账号。程序会把 Markdown 转为 LaTeX，再调用原模板排版；封面、章节编号、目录和参考文献由编译流程处理。

## 第一次使用，从这里开始

**Windows 新手请下载完整运行包。** 前往 [Releases 下载页面](https://github.com/Kayvion-Hong/xit-markdown-thesis-assistant/releases)，在版本的 Assets 中选择 `xit-v0.6.0-beginner-windows.zip`。GitHub 自动提供的 `Source code (zip)` 只有源码，不包含运行环境。

[下载 v0.6.0 Windows 完整包](https://github.com/Kayvion-Hong/xit-markdown-thesis-assistant/releases/download/v0.6.0/xit-v0.6.0-beginner-windows.zip) · [下载校验文件](https://github.com/Kayvion-Hong/xit-markdown-thesis-assistant/releases/download/v0.6.0/xit-v0.6.0-beginner-windows.zip.sha256)

完整包约 381 MB。下载完成后再解压，建议为解压、编译和备份留出足够磁盘空间。只下载仓库右上角 Code 菜单中的 ZIP，会缺少运行环境。

1. 将完整 ZIP 全部解压到较短的路径，例如 `D:\XIT`。不要在压缩包窗口里直接运行。
2. 打开解压出的 `XIT` 文件夹，双击 `启动论文助手.bat`，在首页“新建 / 打开论文”中新建 AI 教学练习。
3. 保持启动窗口打开。在写作页面点击“立即编译”，确认示例能编译。
4. 按页面“AI 示例教学”的练习修改姓名、一段正文和一张表。
5. 练习后回首页，点击“新建 / 打开论文”，新建自己的论文。

完整操作见 **[新手图文指南](docs/GETTING_STARTED.md)**。遇到启动、字体或编译问题，查阅 [常见问题](docs/TROUBLESHOOTING.md)。

### 解压后应该看到什么

找到同时包含这几个文件的文件夹：

```text
XIT/
├── 启动AI示例教学.bat
├── 启动论文助手.bat
├── markdown/
└── runtime/
```

压缩软件可能额外套一层同名文件夹，只要继续进入，找到两个启动文件即可。整个目录一起保留，不能只把 BAT 拖到桌面运行。

### 启动后检查什么

![启动页：先确认运行环境，再生成示例 PDF](docs/images/01-home.png)

第一次建议运行“启动AI示例教学.bat”。页眉应显示“AI 示例论文教学助手”，页面会说明当前是独立的教学项目。开始页检查环境是否齐全；出现缺失项时，先完整解压运行包，再尝试启动。

| 页面里的名称 | 用来做什么 | 新手是否需要手动调用 |
| --- | --- | --- |
| Python | 运行本地网页助手 | 完整包通过启动文件调用 |
| Pandoc | 将 Markdown 转成 LaTeX | 由编译按钮调用 |
| XeLaTeX | 按模板生成 PDF | 由编译按钮调用 |
| Biber | 处理参考文献与引用 | 由完整编译流程调用 |
| 模板常用字体 | 决定 PDF 的字形与排版 | 缺失时需根据提示处理 |

启动时出现的命令窗口需要保持打开。浏览器未自动打开时，把窗口中显示的 `http://127.0.0.1:端口/` 地址复制到浏览器；具体端口以你的窗口为准，不要照抄别人的地址。

第一份示例 PDF 成功生成后，先检查封面、目录和正文，再开始修改。这样后续出现问题时，更容易判断是环境问题还是刚输入的内容需要调整。

## 可以做什么

| 写作任务 | 对应操作 |
| --- | --- |
| 填写封面、关键词 | 表单填写，不必手改 YAML |
| 增减和调整章节 | 新增、改名、排序、移出和恢复，五章只是示例 |
| 边写边看 | 停止输入后自动编译，也可手动编译；整篇 PDF 连续滚动 |
| 查找对应位置 | 双击正文，在 Markdown 和 PDF 之间按段落或内容块定位 |
| 调整阅读大小 | 适合宽度、适合整页、25% 至 300% 缩放、大字阅读 |
| 插入图表和引用 | 图片上传、三线表、编号公式、文献选择和 BibTeX 导入 |
| 找回修改 | 自动保存、本地草稿恢复、撤销重做、文件历史和整篇备份 |

预览需要完成编译后才会更新。它不是逐字即时排版，也不提供多人云端协作。复杂数学公式仍需基本 LaTeX 语法。

| | Windows 完整包 | 本仓库源码 |

原模板字体依赖本机授权安装的字体。包内提供开源替代字体以便预览，但替换后字形和分页可能变化，不能据此保证与原模板完全一致。详见 [Windows 兼容与环境修复](Windows兼容与环境修复.md)。

## 跟着 AI 示例练习

随包教学项目为《基于 STM32 的智能照明系统设计》，与普通论文使用不同目录。建议一次只改一处，保存、编译，再观察变化。

![AI 示例教学入口及分步练习](docs/images/07-ai-tutorial.png)

示例中的数据、图表、结论和部分文献用于排版教学，未经真实研究验证，不应直接作为研究成果提交。教程包括封面、正文、图片、表格、公式、文献、章节增减和代码附录。详见 [AI 示例教学手册](AI示例教学手册.md)。

先完成下面四项，就能熟悉日常写作的主要操作。每项都有更详细的[图文实操步骤](docs/AI_WALKTHROUGH.md)。

| 练习 | 具体修改 | 编译后检查 |
| --- | --- | --- |
| 改封面 | 在“填写资料”把“张三”改成“练习学生” | 封面姓名更新 |
| 改正文 | 在绪论第一段后增加一句练习文字 | PDF 中能找到这句话 |
| 加一张表 | 在第二章用“三线表”粘贴两列练习数据 | 表题、横线和引用编号正常 |
| 恢复修改 | 撤销刚插入的内容，或查看修改前的文件历史 | 编辑区恢复，再编译确认 PDF 更新 |

之后再练习图片、公式、文献和章节增减。[完整教学演示](docs/AI_WALKTHROUGH.md)为每项练习写明了成功标准和恢复方法；示例来源与转换说明保留在 [AI 示例教学手册](AI示例教学手册.md)。

## 从示例转到自己的论文

练习结束后回首页，通过“新建 / 打开论文”创建自己的项目。普通论文与教学练习分别保存：

| 入口 | 编辑的目录 | 正式生成的 PDF |
| --- | --- | --- |
| 首页新建论文 | 用户文档目录下的独立项目 / `thesis/` | 该项目的 `build/thesis.pdf` |
| 首页新建 AI 教学练习 | 另一个独立项目 / `thesis/` | 该项目的 `build/thesis.pdf` |

首页显示实际保存路径。程序内的 `markdown/thesis/` 和 `markdown/examples/ai/thesis/` 用于创建副本。旧的 AI 启动文件仍保留，但新手可统一使用普通启动入口。

普通项目中也有占位内容。开始写作后逐项替换资料、摘要、章节、图表及文献，不能把“普通项目”理解为已经可以提交的成品。

### 填写封面与关键词

![填写资料：在表单里编辑题目、姓名和关键词](docs/images/02-metadata.png)

在“2 填写资料”中填好中英文题目、姓名、学号、专业、年级、指导教师、日期和关键词。点击“保存基本资料”，或等待页眉显示“内容已同步”，然后重新编译检查封面。

关键词按输入框提示用逗号分隔。长题目可能超出封面栏宽，程序会提示修改；请结合指导教师意见调整题目，不能仅靠缩小浏览器显示比例解决 PDF 排版问题。

### 学会最常用的 Markdown

进入“3 写论文”，通过“当前内容”切换摘要、正文、总结、谢辞、附录和参考文献库。章标题已有内容时，修改原标题即可，不要再插入第二个一级标题。

```markdown
# 绪论

## 研究背景

这里写第一段正文。需要强调的词语可以写成 **关键术语**。

这里是第二段正文。两个段落之间留一个空行。

### 研究对象

继续填写本节内容。
```

| 写法 | 含义 | 容易出错的地方 |
| --- | --- | --- |
| `# 绪论` | 章标题 | `#` 后留空格，每章保留一个一级标题 |
| `## 研究背景` | 节标题 | 章、节编号由模板生成，不必手写 |
| `### 研究对象` | 小节标题 | 按内容层级使用，不用它调整普通文字字号 |
| `**关键术语**` | 加粗 | 两端都需要两个星号 |
| 段落之间空一行 | 分成两个段落 | 单次回车不一定得到独立段落 |
| `[@文献代号]` | 引用文献 | 代号必须与文献库一致 |

摘要只写正文，不添加 `# 摘要`。插入图片、三线表和编号公式时，先把光标放到完整段落后的空行，再点击工具栏按钮。数学公式仍使用 LaTeX 数学语法；可以先从 `y = ax + b` 开始练习。

### 预览、缩放与双向定位

保存成功后，勾选“停止输入 3 秒后自动编译”可自动更新预览；也可以点击“立即编译”。自动保存与自动编译是两件事：前者把文字写入文件，后者生成新的 PDF。关闭自动编译仍可继续写作和保存。

在右侧 PDF 上使用滚轮，可连续阅读所有页。页码输入框表示 PDF 的页序号，可能与正文页脚的印刷页码不同。缩放可选“适合宽度”“适合整页”或 25% 至 300%，也可填写百分比。缩放只改变屏幕显示，不改变导出字号。

先成功编译一次，再双击左侧正文，或点击“定位到 PDF”；在 PDF 正文上双击，可以回到对应内容块。定位按段落或内容块进行，封面、目录和自动生成的参考文献不保证逐字对应。刚改完内容还没编译时，应先等新结果生成。

### 增减章节

![章节管理：五章只是示例，可按论文结构增减](docs/images/04-chapters.png)

点击“管理章节（增减 / 排序）”，通过“＋ 新增一章”输入章名；用“上移”“下移”调整顺序。“移出正文（保留文件）”会让该章停止参与编译，之后可以恢复到正文末尾，至少需保留一章。

重新编译后检查目录。诸如“全文共分为五章”的正文叙述，以及对移出章节中图表的引用，需要作者自己调整。

### 管理参考文献

![文献引用：选择已有条目，也可填写新文献或导入 BibTeX](docs/images/05-references.png)

把光标放在需要引用的句子末尾，点击“文献引用”。第一次先选择示例中的已有条目，理解从 `[@代号]` 到 PDF 引用编号的变化。写自己的论文时，可填写真实文献，或从文献来源导出 `.bib` 文件再导入。

导入后还需选择条目插入正文；单独把文献放进库中，不等于已经在论文里引用。手动填写时按来源填写作者、题名、年份等信息，多位作者按窗口提示用 `and` 分隔。BibTeX 导入目前限制为 2 MB，重复代号等问题应按提示解决。

参考文献库可通过“当前内容”查看。新手先用文献按钮操作，熟悉后再手动编辑原始条目。示例里存在占位文献，正式引用前必须核验。

## 保存和恢复

正文停止输入约 1.2 秒后自动保存，基本资料约 1.6 秒后保存。以页面“内容已同步”为准；保存失败时应先处理提示。`Ctrl+S` 可以立即保存，`Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。

未同步的修改还会尝试保存在浏览器本地草稿中。恢复依赖原浏览器、访问地址和项目位置；清理浏览器数据、移动项目或磁盘故障可能使恢复失效。请定期把整篇备份另存到其他磁盘。具体区别见[图文指南](docs/GETTING_STARTED.md)。

![整篇备份：大幅改动前保存一个可识别的版本](docs/images/06-backup.png)

| 功能 | 适合什么情况 | 使用时注意 |
| --- | --- | --- |
| 撤销、重做 | 刚打错或刚插错内容 | 是编辑过程中的操作记录，不等于重启后的永久历史 |
| 自动保存 | 日常连续写作 | 离开前确认“内容已同步”；保存失败要先处理 |
| 本地草稿 | 意外关闭前还有未同步文字 | 用原浏览器、原地址和原项目位置尝试恢复 |
| 历史版本 / 恢复 | 找回某个文件较早的内容 | 核对文件、时间和预览，再确认恢复 |
| 整篇备份 / 回退 | 结构调整或大幅修改前留档 | 包含资料、正文、文献和图片，定期另存到其他磁盘 |

正常结束写作时，先保存、确认同步，再点击“关闭助手”。下次仍双击同一文件夹中的启动文件。如果页面提示草稿恢复，先查看内容，不要急着清空浏览器数据或覆盖项目目录。

## 检查与导出 PDF

![检查与导出：结构检查、生成 PDF 与定稿检查](docs/images/08-export.png)

1. 在写作页点击“返回功能菜单”，进入“4 检查与导出”。
2. 点击“开始检查”，处理提示的缺失图片、引用和标签问题。结构检查不生成 PDF。
3. 点击“生成 PDF”，等待成功后打开生成结果。缺少原模板字体时，可先使用随包字体生成预览。
4. 正式提交前做“定稿检查”，补齐占位信息，并人工逐页复核。

建议人工检查：封面题目和个人信息是否正确；目录是否更新；图片是否清晰、图题是否对应；表格有没有超宽或异常换行；公式和引用是否出现问号；参考文献是否真实且与正文相关；总结、谢辞和附录是否齐全。

编译成功表示软件生成了 PDF，不能代替学院格式审核或学术内容审核。查看之前已打开的 PDF 标签页时，必要时刷新，确认看到本次结果。

## 常见问题速查

| 问题 | 先尝试这一步 |
| --- | --- |
| 找不到 Python、Pandoc 或 Biber | 确认下载的是完整运行包，`runtime` 已完整解压 |
| 解压提示路径太长 | 重新解压到短路径，不跳过报错文件 |
| 双击后浏览器没打开 | 查看启动窗口，把其中本机地址复制到浏览器 |
| 提示端口占用 | 关闭同一项目的旧助手后再启动 |
| 左侧改了，右侧还没变化 | 确认保存成功且本次编译成功，查看预览状态 |
| 公式、图片或文献引用有问号 | 核对标签、文件路径和文献代号，重新完整编译 |
| 编译失败 | 找最先出现的具体错误和文件位置，再修改 |
| 意外关闭后怕丢内容 | 原位置重新启动，检查草稿提示、文件历史和备份 |

更多处理方法见[常见问题](docs/TROUBLESHOOTING.md)。请不要为了尝试修复而把新 ZIP 直接覆盖到已有论文目录。

## 离线、迁移与更新

运行环境、图片、字体和所需宏包已在本机时，常规写作与编译可以离线进行。本机网页不会自动把论文同步到 GitHub，也没有多人协作编辑功能。把 PDF 发给教师审阅，需要你另行发送导出文件。

换电脑前先等待内容同步，处理未恢复草稿，关闭助手，再复制整个项目文件夹。浏览器草稿不会跟随文件夹自动迁移，重要内容应先恢复并保存成文件。

更新程序时先导出项目 ZIP，再将新版本解压到独立目录。v0.6 的论文保存在程序目录之外，升级后可继续打开；从 v0.5 导入的具体步骤见[迁移说明](docs/UPGRADE_0_6.md)。有自定义配置时先在副本中试编译。
